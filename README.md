# 记一笔

手机上用的记账本：分大类、小类记账，按月、按年汇总。数据只存在手机上，不上传。

## 装到 iPhone

1. 用相机扫二维码，在 Safari 里打开
2. 点「分享」（新版 iOS 在「⋯」里）→「添加到主屏幕」→「添加」
3. 以后从主屏幕的图标打开。打开过一次之后，断网也能用

## 数据

- 存在这台手机上「记一笔」自己的本地数据库里（IndexedDB），不会上传到任何服务器
- 删掉主屏幕图标，数据会跟着一起删掉
- 设置 →「备份全部数据」：导出 .json 文件，存到「文件」或 iCloud 云盘；换手机时用「从备份恢复」导回来
- 设置 →「导出表格」：导出 CSV，Excel 和 Numbers 都能打开

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` `app.css` `app.js` | 页面本身 |
| `sw.js` | 离线缓存；发布新版本时要改里面的 `VERSION` |
| `manifest.webmanifest` `icons/` | 主屏幕上显示的名字和图标 |
| `qr.png` | 安装用的二维码，发布时生成 |
